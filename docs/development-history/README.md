# Development history

This archive preserves the project's existing build documentation: feature reasoning, implementation plans, AI-assisted design prompts, code reviews and verification evidence. Shared and Android records live together here; active operating instructions live in [guides](../README.md).

Read the [timeline](timeline.md) for chronological navigation. The dates in its inventory come from first/last Git commits touching each document, not inferred project start dates. The body of a document can record an earlier work date. Plans, test counts, source line numbers and unresolved findings describe the recorded snapshot.
