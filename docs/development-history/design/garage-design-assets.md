# Android garage artwork

Generated with the built-in ImageGen tool for the garage collection redesign. Both assets use transparent backgrounds and are bundled locally as resized WebP files; there are no runtime image requests.

- `pulse-android/feature/garage/src/main/res/drawable-nodpi/garage_vehicle.webp`: common placeholder for every vehicle. Replace with vehicle-specific photos when the data model supports them.
- `pulse-android/feature/garage/src/main/res/drawable-nodpi/garage_workshop.webp`: decorative workshop in the wide-screen header.

The API currently supplies only vehicle names. The UI deliberately omits the reference's category, engine capacity, and fuel badges instead of inventing specifications.

## Vehicle prompt

Use case: product-mockup. Asset type: Android garage vehicle card placeholder. Generate one beautiful realistic unbranded adventure motorcycle, sand beige fuel tank, black seat and frame, side / three-quarter view facing right, full vehicle visible including both wheels, isolated on genuinely transparent background, soft subtle grounding shadow only. Clean premium catalog photography, warm studio light. No scenery, no lettering, no logos, no border. Compact landscape composition with minimal empty margins.

## Workshop prompt

Soft hand-rendered 3D illustration with delicate outlines and soft warm shading, front facing with slight depth. A pale buttery yellow abstract oval behind building, tiny amber sparkles. Landscape composition, full subject visible, genuinely transparent outer background. No vehicles, people, lettering, logos or text.
